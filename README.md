# YouTube Slide Generator

Up塾のYouTube教材向けに、説明文とスキャン画像から統一デザインのスライドPNGを生成する静的Webアプリです。

## アプリの目的

- YouTube動画で使う教材スライドを、ブラウザ上で素早く作成する。
- 入力した説明文を段落ごと、またはスライド番号つきテキストごとに分割し、複数枚の16:9スライドとして表示する。
- 生成後にスライドのタイトル・本文・枚数・順番を人間が直接調整する。
- スキャン画像をスライド内の画像エリアへ配置する。
- 編集後のスライドをPNGとして保存し、Vrewなどの動画編集工程で使える素材にする。
- PowerPointのpptxに相当するプロジェクト保存として、編集途中の状態をJSONで保存・読み込みし、あとから再編集できるようにする。

## 使い方

1. `index.html` をブラウザで直接開きます。
   - `index.html`、`style.css`、`script.js` は同じ階層に置き、HTMLからは `./style.css` と `./script.js` で読み込みます。
   - そのため、ローカルサーバーを使わず `file://` で開いてもCSSとアプリ本体のJavaScriptは読み込まれます。
2. どちらかの入力欄にスライド化したい文章を入力します。
   - 従来方式を使う場合は「説明文・台本（空行ごとに分割）」に入力します。
   - スライド番号を明示したい場合は「スライド分解テキスト」に入力します。
3. 必要に応じて「スキャン画像」から画像をアップロードします。
   - 複数枚アップロードした場合、2枚目以降のスライドに順番に配置されます。
4. 入力方式に合わせて「スライド生成」または「スライド分解テキストから生成」ボタンを押します。
5. 生成結果の各スライド上部にある編集欄・操作ボタンで、タイトル、本文、削除、複製、順番変更を調整します。
6. 編集途中の状態をあとから再編集したい場合は、「JSON保存」ボタンでプロジェクトJSONを保存します。
7. 保存したプロジェクトを再編集する場合は、「JSON読み込み」ボタンで保存済みJSONファイルを選択します。
8. 各スライドの「このスライドをPNG保存」ボタンで1枚ずつ保存できます。
9. 「全スライドを連番PNG保存」ボタンで、編集後の状態を `upjuku-slide-001.png` のような連番PNGとして保存できます。

## 入力形式

### 1. 空行ごとに分割する従来方式

「説明文・台本（空行ごとに分割）」では、空行で区切った1段落が1枚のスライドになります。

```text
一次関数のグラフを読み取ろう

今日は、一次関数のグラフから傾きと切片を見つける練習をします。

傾きは「右に1進んだとき、上にいくつ進むか」で考えます。
```

- 1段落目はタイトルスライドになります。
- 2段落目以降は説明スライドになります。
- 画像がある説明ページは「画像＋説明スライド」になります。

### 2. スライド分解テキスト方式

「スライド分解テキスト」では、ChatGPTなどで分解した結果を貼り付け、人間があとから1枚目、2枚目……を直接直せる形式で管理できます。

```text
--- slide 1
タイトル：一次関数のグラフを読み取ろう
本文：今日は、一次関数のグラフから傾きと切片を見つける練習をします。

--- slide 2
タイトル：まず見る場所
本文：グラフが右上がりか右下がりかに注目します。

--- slide 3
タイトル：傾きの考え方
本文：傾きは「右に1進んだとき、上にいくつ進むか」で考えます。
```

読み取りルールは次のとおりです。

- `--- slide 1`、`--- slide 2` のような行をスライドの区切りとして扱います。
- `タイトル：` または `title:` の後ろをスライドタイトルとして扱います。
- `本文：`、`body:`、`text:` の後ろを本文として扱います。
- スライド番号がある場合は、番号順に並べて生成します。
- 区切り線やラベルが多少崩れていても、先頭行をタイトル、残りを本文としてできるだけ生成します。
- 現時点ではOpenAI APIなどの外部AI連携はありません。外部で分解したテキストを貼り付けて使う前提です。

## 生成後の編集

生成後の各スライドには、プレビューの上に編集欄と操作ボタンが表示されます。

- タイトル編集: タイトル入力欄を変更すると、すぐ下のスライドプレビューに反映されます。
- 本文編集: 本文テキストエリアを変更すると、改行を保ったままスライドプレビューに反映されます。
- スライド削除: 対象スライドを削除します。誤操作防止のため、最後の1枚は削除できません。
- スライド複製: 対象スライドを次の位置にコピーします。
- 順番変更: 「上へ」「下へ」でスライドの順番を変更します。
- PNG出力: 編集欄ではなく、下のスライドプレビュー部分だけをPNG化します。

## JSONプロジェクト保存・読み込み

JSON保存は、生成・編集したスライドをあとから再編集するためのプロジェクト保存機能です。PowerPointの `.pptx` に相当する作業ファイルとして使い、最終出力用のPNGとは別に編集状態を保持できます。

### JSON保存の使い方

1. 空行分割方式またはスライド分解テキスト方式でスライドを生成します。
2. 必要に応じて、タイトル編集、本文編集、削除、複製、上へ/下へ移動を行います。
3. 「JSON保存」ボタンを押します。
4. `upjuku-slide-project-YYYYMMDD-HHMMSS.json` 形式のファイル名で、現在のスライド状態がダウンロードされます。

保存される主な内容は次のとおりです。

- スライド順
- 各スライドのID
- `type`
- `title`
- `body`
- `imageDataUrl`
- 作成日時
- アプリバージョン

### JSON読み込みの使い方

1. 「JSON読み込み」ボタンを押します。
2. 以前「JSON保存」で保存した `.json` ファイルを選択します。
3. スライド一覧が復元され、読み込み後もタイトル編集、本文編集、削除、複製、上へ/下へ移動、個別PNG保存、全スライド連番PNG保存ができます。

不正なJSONや、このアプリ用ではないJSON、`slides` 配列がないJSONを選んだ場合は、読み込みを中止し、画面の `alert` で理由を表示します。

### 画像入りJSONの注意

画像を含むスライドでは、画像データを `imageDataUrl` としてJSON内に保存します。そのため、画像の枚数や解像度が大きいほどJSONファイルサイズも大きくなります。共有や保管を行う場合は、ファイルサイズに注意してください。

## ファイル構成

```text
.
├── index.html              # 入力フォーム、編集UI、プレビュー領域、CSS/JS/ライブラリ読み込み
├── style.css               # Up塾向けデザイン、CSS変数、スライドテンプレート、編集UI
├── script.js               # 段落分割、分解テキスト解析、編集操作、JSON保存・読み込み、スライドHTML生成、PNG出力処理
├── README.md               # このドキュメント
├── assets/
│   ├── images/             # 教材画像などを置く場所
│   └── characters/         # キャラクター素材などを置く場所
└── docs/
    ├── architecture.md     # 現在の設計メモ
    ├── codex_report.md     # Codex作業報告
    ├── next_tasks.md       # 今後の作業候補
    └── project_status.md   # プロジェクト状況
```

## ローカルファイルで開くときの注意

- `index.html`、`style.css`、`script.js` が同じフォルダにある前提で動作します。
- CSSとアプリ本体のJavaScriptは相対パス `./style.css`、`./script.js` で指定しているため、`index.html` を直接ダブルクリックして開いても読み込めます。
- PNG保存機能だけは外部CDNの `html2canvas` に依存しているため、オフライン環境では保存ボタン実行時に動かない可能性があります。

## Vrewとの役割分担

このアプリは、動画編集の前段階で使う「スライド画像の作成」に集中します。

- このアプリが担当すること
  - 台本入力
  - 段落ごとのスライド分割
  - スライド番号つきテキストからの生成
  - 生成後のスライド編集
  - 統一レイアウトの適用
  - PNG画像の出力
  - JSONプロジェクト保存・読み込みによる再編集
- Vrewが担当すること
  - 字幕作成
  - 音声読み上げ・ナレーション
  - 動画タイムライン編集
  - BGM、効果音、書き出し

## テンプレート

現在は、以下の3種類のテンプレートを用意しています。

1. タイトルスライド
2. 説明スライド
3. 画像＋説明スライド

デザインの色、文字サイズ、余白、影などは `style.css` のCSS変数から調整できます。

# YouTube Slide Generator

Up塾のYouTube教材向けに、説明文とスキャン画像から統一デザインのスライドPNGを生成する初期版Webアプリです。

## アプリの目的

- YouTube動画で使う教材スライドを、ブラウザ上で素早く作成する。
- 入力した説明文を段落ごとに分割し、複数枚の16:9スライドとして表示する。
- スキャン画像をスライド内の画像エリアへ配置する。
- 生成したスライドをPNGとして保存し、Vrewなどの動画編集工程で使える素材にする。

## 使い方

1. `index.html` をブラウザで直接開きます。
   - `index.html`、`style.css`、`script.js` は同じ階層に置き、HTMLからは `./style.css` と `./script.js` で読み込みます。
   - そのため、ローカルサーバーを使わず `file://` で開いてもCSSとアプリ本体のJavaScriptは読み込まれます。
2. 「説明文・台本」にスライド化したい文章を入力します。
   - 空行で区切った1段落が1枚のスライドになります。
   - 1段落目はタイトルスライドになります。
   - 2段落目以降は説明スライドになります。
3. 必要に応じて「スキャン画像」から画像をアップロードします。
   - 複数枚アップロードした場合、2枚目以降のスライドに順番に配置されます。
4. 「スライド生成」ボタンを押すと、ブラウザ上にプレビューが表示されます。
5. 各スライドの「このスライドをPNG保存」ボタンで1枚ずつ保存できます。
6. 「全スライドを連番PNG保存」ボタンで、`upjuku-slide-001.png` のような連番PNGとして保存できます。

## ローカルファイルで開くときの注意

- `index.html`、`style.css`、`script.js` が同じフォルダにある前提で動作します。
- CSSとアプリ本体のJavaScriptは相対パス `./style.css`、`./script.js` で指定しているため、`index.html` を直接ダブルクリックして開いても読み込めます。
- PNG保存機能だけは外部CDNの `html2canvas` に依存しているため、オフライン環境では保存ボタン実行時に動かない可能性があります。

## Vrewとの役割分担

このアプリは、動画編集の前段階で使う「スライド画像の作成」に集中します。

- このアプリが担当すること
  - 台本入力
  - 段落ごとのスライド分割
  - 統一レイアウトの適用
  - PNG画像の出力
- Vrewが担当すること
  - 字幕作成
  - 音声読み上げ・ナレーション
  - 動画タイムライン編集
  - BGM、効果音、書き出し

## テンプレート

初期版では、以下の3種類のテンプレートを用意しています。

1. タイトルスライド
2. 説明スライド
3. 画像＋説明スライド

デザインの色、文字サイズ、余白、影などは `style.css` のCSS変数から調整できます。

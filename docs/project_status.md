# プロジェクト状況

## 現在の状態

- 静的Webアプリとして、説明文の段落分割、画像アップロード、3テンプレートのスライド生成、PNG保存に対応しています。
- `index.html`、`style.css`、`script.js` が同じ階層にある場合、`index.html` を直接開いてもCSSとアプリ本体のJavaScriptが読み込まれるように、相対パスを `./style.css` と `./script.js` で明示しています。
- 新しく「スライド分解テキスト」入力欄と「スライド分解テキストから生成」ボタンを追加済みです。
- `--- slide 1`、`タイトル：`、`本文：` 形式のテキストから、スライド番号順にスライド生成できます。
- 生成後のスライドについて、タイトル編集、本文編集、削除、複製、上へ/下への順番変更ができます。
- 編集後のプレビュー状態で、個別PNG保存と連番PNG一括保存ができます。

## 動作方法

ブラウザで `index.html` を直接開くか、以下のようにローカルサーバーを起動して確認します。直接開く場合も、CSSとアプリ本体のJavaScriptは同階層のローカルファイルから読み込まれます。

```bash
python3 -m http.server 4173
```

その後、`http://127.0.0.1:4173/` を開きます。

## 既知の注意点

- CSSとアプリ本体のJavaScriptはローカル同階層ファイルから読み込みます。
- PNG保存には `html2canvas` のCDN読み込みが必要です。オフラインで `index.html` を直接開いた場合、スライド生成と編集はできますがPNG保存は動かない可能性があります。
- スライド分解テキスト解析は、多少の崩れを許容する簡易パーサーです。複雑な入れ子構造やMarkdown全体の厳密解析は行いません。
- 生成後編集はブラウザメモリ上の一時状態です。ページを再読み込みすると編集内容は消えます。
- 一括保存はブラウザのダウンロード制限を受ける場合があります。

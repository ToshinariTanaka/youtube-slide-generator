# プロジェクト状況

## 現在の状態

- 初期版の静的Webアプリを実装済みです。
- 説明文の段落分割、画像アップロード、3テンプレートのスライド生成、PNG保存に対応しています。

## 動作方法

ブラウザで `index.html` を直接開くか、以下のようにローカルサーバーを起動して確認します。

```bash
python3 -m http.server 4173
```

その後、`http://127.0.0.1:4173/` を開きます。

## 既知の注意点

- PNG保存には `html2canvas` のCDN読み込みが必要です。
- 段落分割は単純な空行区切りです。
- 一括保存はブラウザのダウンロード制限を受ける場合があります。

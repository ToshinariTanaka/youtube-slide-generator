# プロジェクト状況

## 現在の状態

- 静的Webアプリとして、説明文の段落分割、画像アップロード、基本3テンプレートのスライド生成、`図表：` からの簡易SVG図表付きスライド生成、PNG保存に対応しています。
- `index.html`、`style.css`、`script.js` が同じ階層にある場合、`index.html` を直接開いてもCSSとアプリ本体のJavaScriptが読み込まれるように、相対パスを `./style.css` と `./script.js` で明示しています。
- 「スライド分解テキスト」入力欄と「スライド分解テキストから生成」ボタンに対応済みです。
- `--- slide 1`、`タイトル：`、`本文：`、`図表：` 形式のテキストから、スライド番号順にスライド生成できます。
- 生成後のスライドについて、タイトル編集、本文編集、図表指示編集、削除、複製、上へ/下への順番変更ができます。
- 編集後のプレビュー状態で、個別PNG保存と連番PNG一括保存ができます。
- 「JSON保存」ボタンで、現在編集中のスライド順、ID、type、title、body、imageDataUrl、diagramPrompt、作成日時、アプリバージョンを含むプロジェクトJSONを保存できます。
- 「JSON読み込み」ボタンで、保存済みプロジェクトJSONを読み込み、スライド一覧を復元して再編集できます。
- 不正なJSON、このアプリ用ではないJSON、`slides` 配列がないJSONは `alert` でエラー表示して読み込みを止めます。

## 動作方法

ブラウザで `index.html` を直接開くか、以下のようにローカルサーバーを起動して確認します。直接開く場合も、CSSとアプリ本体のJavaScriptは同階層のローカルファイルから読み込まれます。

```bash
python3 -m http.server 4173
```

その後、`http://127.0.0.1:4173/` を開きます。

## 既知の注意点

- CSSとアプリ本体のJavaScriptはローカル同階層ファイルから読み込みます。
- PNG保存には `html2canvas` のCDN読み込みが必要です。オフラインで `index.html` を直接開いた場合、スライド生成、編集、JSON保存・読み込みはできますが、PNG保存は動かない可能性があります。
- スライド分解テキスト解析は、多少の崩れを許容する簡易パーサーです。複雑な入れ子構造やMarkdown全体の厳密解析は行いません。
- JSON保存では画像の `imageDataUrl` も保存するため、画像を含むプロジェクトJSONはファイルサイズが大きくなる可能性があります。
- JSON読み込み後もスライド操作時は既存仕様に合わせてスライドタイプを正規化します。`diagramPrompt` がある画像なしスライドは `diagramExplanation` として保持します。
- 図表生成はキーワードベースの簡易SVGプレースホルダーです。汎用AI連携や自由なSVG生成は未実装です。
- 一括保存はブラウザのダウンロード制限を受ける場合があります。

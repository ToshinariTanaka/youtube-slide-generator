## テスト結果

- `python3 -m http.server 4173` でローカルサーバーを起動し、HTTP 200で `index.html` を取得できることを確認しました。
- `node --check script.js` でJavaScriptの構文エラーがないことを確認しました。
- Playwright、Chromium、Firefoxなどのブラウザ実行環境が見つからなかったため、実ブラウザでのスクリーンショット取得は未実施です。
- 代替確認として、HTMLの主要ID、ローカルCSS/JS参照、必要ディレクトリの存在をPythonスクリプトで静的検証しました。

## 注意点

- PNG出力にはCDNから読み込む `html2canvas` が必要です。オフライン環境ではPNG保存が動かない可能性があります。
- 全スライド保存はブラウザの連続ダウンロード制限に影響される場合があります。
- 現時点のスライド分割はAIではなく、空行区切りの単純な段落分割です。
- 1920×1080相当の出力を狙うため、画面表示は960×540のプレビューを `html2canvas` の `scale: 2` でPNG化しています。

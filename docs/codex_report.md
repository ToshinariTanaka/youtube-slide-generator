## 注意点

- PNG保存は引き続き外部CDNの `html2canvas` に依存します。オフライン環境ではスライド生成・編集はできてもPNG保存だけ動かない可能性があります。
- 生成後編集はブラウザ上の一時状態です。ページを再読み込みすると編集内容は失われます。
- スライド分解テキスト解析は、人間が編集しやすい簡易形式を優先した実装です。複雑なMarkdownや入れ子構造を厳密に解析するものではありません。
- 実ブラウザでのスクリーンショット確認とPNG保存の実操作確認は、今回の環境では未実施です。

# 今後の作業候補

## 優先度高

- 実ブラウザでJSON保存、JSON読み込み、読み込み後の編集操作、PNG保存の手動確認を行う。
- 画像入りJSONのファイルサイズが実運用で問題にならないか確認する。
- 画像の表示位置、拡大率、トリミングを調整できるようにする。

## 優先度中

- 図表指示が空になった場合に通常スライドへ戻す編集UIを検討する。
- プロジェクトJSONのスキーマ変更が必要になった場合の移行ルールを決める。
- AI連携による本格的なSVG図表生成を検討する。
- 図表タイプ別（graph / comparison / flow / relation / card）のキーワードとテンプレート表現を増やす。
- テンプレートを手動選択できるUIを追加する。
- ZIP一括ダウンロードを実装する。
- 文字数が多い本文への警告や、自動縮小・自動分割の補助を追加する。
- 強調語句にマーカー色を付ける記法を追加する。

## 優先度低

- Up塾キャラクター素材の配置パターンを追加する。
- キーボードショートカットを追加する。
- スライド分解テキストを画面上の編集結果から再生成する機能を追加する。
- 画像なしJSON保存モードや軽量保存モードを検討する。
